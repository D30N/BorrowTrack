# BorrowTrack

A simple, private IOU tracker for Android — keep track of what you lent and borrowed, with due-date reminders.

- 📋 Lent / Borrowed entries (person, item, date, due date, note) — 100% offline
- 🔔 Notification on the due date (9 AM)
- 📜 History with press-and-hold to delete
- 💬 One-tap WhatsApp reminder
- 🇮🇳 Malayalam-first UI

Built with native Kotlin, no dependencies beyond AndroidX Core.

## Build

```bash
bash app/offline-build.sh assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`
